**新增「手势导航条同色」：屏幕底部那条小白条不再是纯黑 / 纯白。**

## 本版内容

- 新增：手势导航条同色。屏幕底部的手势导航条区域填充与紧邻界面一致的颜色，
  深色与浅色模式下都融进整体视觉，不再是一条生硬的纯黑或纯白。
  开关在「功能 → 显示」分组里，出厂默认关。

## 注意

- 开关从「关」改成「开」后，需要**重启一次金太阳**才生效；从「开」改成「关」是立刻还原的。
- 本功能只改「底部那条填什么颜色」这**一个**窗口属性，**不做沉浸**
  （不把内容铺到屏幕物理底边）。所以那条区域仍然是一块纯色 ——
  上方界面是渐变 / 图片 / 圆角卡片时，交界处可能仍有可见色差。
- 三键导航（非手势）下只改颜色、保留系统的强制对比度，以保证那三个按键始终看得见。
- 本版没有破坏性变更，直接覆盖安装即可。
