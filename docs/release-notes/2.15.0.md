**新功能：界面精简** —— 把主界面上用不到的东西去掉、把太高的东西压矮。
五个开关，**出厂全部关闭**，打开模块 App 到「功能」页自选。

## 本版内容

- **新增「底栏精简」**：主界面底栏不再显示「理财」那一格，其余入口自动均分铺满整行。
- **新增「首页精简」**：首页快捷入口下方的那条横幅不再显示，下面的内容顺势上移。
- **新增「行情市场精简」**（三个开关，可单独开）：
  - **隐藏滚动横幅与快捷入口**：概览图下方的滚动快讯、以及它下面那排快捷入口一并隐藏，
    板块直接顶上来；
  - **板块由六项压到三项**：板块区只留最上面三个，整体变矮；
  - **压缩市场概览**：概览区整体压矮，里面的柱状图高度一并压缩。
- **新增三个功能分区**：「底栏精简」「首页精简」「行情市场精简」。

## 注意

- 五个开关**出厂默认关闭**，打开模块 App →「功能」页里按需开启。
- 开关从「关」改成「开」后，需要**重启一次金太阳**才生效；
  从「开」改成「关」是**立刻还原**的。
- 万一某个开关开了没效果，去「设置 → 日志输出等级」调成「调试」，
  重启金太阳进一次对应页面，再到「设置 → 查看日志」看看 ——
  模块会把那页的界面结构打出来，反馈 Issue 时附上这段日志，能一次定位。
- 本版**没有**破坏性变更：包名、配置项全部不变，直接覆盖安装即可，原有开关状态不受影响。
