**新功能：个股详情页底栏「智能盯盘」快捷入口。**

## 本版内容

- **新增「底栏『智能盯盘』入口」**：个股 / 指数详情页底栏的「自选」与「更多」之间多一颗
  「智能盯盘」，**一点直达**，不用再进「更多」里翻第二层。买 / 卖的宽度会自动让位，
  底栏不换行、不溢出。
- **修复：点它会先闪一下黑**。原因是弹面板时整个页面被临时调暗了一瞬，
  现在那一下已经被拦住，点下去直接进页面。
- **功能菜单新增「股票详情页增强」分区**：这个开关原来挂在「策略页增强」下，
  它改的是详情页，跟策略页没关系，已经挪到正确的分区。

## 注意

- 功能开关**出厂默认关闭**，打开模块 App →「功能」页 →「股票详情页增强」里手动开启。
- 开关从「关」改成「开」后，需要**重启一次金太阳**才生效。
- 本版**没有**破坏性变更：包名、配置键、存储值全部不变，老用户的开关状态不受影响，
  直接覆盖安装即可。
