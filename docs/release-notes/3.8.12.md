## 本版内容

**筛选股票**

- 修复 只勾「涨家」、不勾「自选」时列表里还留着自选票 —— 以前靠市场号认自选，市场号没填好就认不出；现在按自选表的代码集合认，认不出整表时才退回逐只判断。
- 修复 进策略详情页首屏筛错、手点一次「确定」才对 —— 后台那套「每 500ms 采一次屏幕行情、变了就重算」的定时器一直没启动过（三处提前 return 把它一起带走了）；现在进页面就起，筛错会自动纠正。
- 修复 屏幕上行情文案偶尔记到别的股票头上 —— 采集改成认行视图本身，不再按「第几行」去列表里反推。

**勾选加入自选**

- 修复 手机上全选后「确认添加」随机提示「已在该组合」、实际一只没加 —— 宿主提交的代码来自它自己那份残值（常常只剩 6 只甚至 0 只），0 只时分组页会判定「每只都已在组里」；现在按屏幕勾选重写提交包，页面已经关掉也照样校正。
- 修复 含自选股时更容易失败 —— 自选票常常「只有代码、没有市场号」，以前一行读不出就把整批作废；现在市场号缺失按代码前缀推导。

**底层**

- 修复 少数股票名称、面板文案里出现乱码方块。
- 调整 市场号缺失统一按代码前缀推导，筛选、全选、勾选态通道同一口径。
