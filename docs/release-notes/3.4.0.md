**策略详情多选态新增「截图并添加」：按勾选顺序截取每只股票的真实详情页并存入相册，截完直接进入宿主的「选择分组」。**

## 本版内容

**策略页**

- 新增 截图并添加 —— 策略详情多选态底部、「确认添加」左侧；按勾选顺序逐只打开个股详情页，等标题和日 K 数据都加载完整后截图，保存到相册 `Pictures/GSAuxiliary/<时间>/`；数据没加载完的页面会跳过，不会保存半张图；截图完成后自动弹出宿主的「选择分组」，由你选择加入哪个分组。
