**智能盯盘新增价格页一键配置等一批功能，修掉取数失败；设置页可一键导出日志。**

## 本版内容

**智能盯盘**

- 新增 价格页一键配置 —— 功能页 → 智能盯盘；价格页保存按钮右侧，按方案自动填入涨到 / 跌到。
- 新增 盯盘数据卡片拓展 —— 我的盯盘列表，点击数据卡片进入个股详情页。
- 新增 无需确定保存盯盘 —— 保存成功不弹确认，轻提示后自动返回。
- 新增 保存后返回位置设置 —— 保存后回个股详情页，或只回上一页。
- 新增 优化确定逻辑 —— 涨到、跌到为空时仍可保存，即把该股移出我的盯盘。
- 新增 最近前高 / 最近前低 —— 取值项取现价上方 / 下方最近的波段点。
- 新增 配置按钮设置 —— 多方案时是否弹出选择方案弹窗。
- 调整 配置并保存只在价格页出现 —— 涨跌幅、换手率等页签不再显示这颗按钮。

**修复**

- 修 取数失败 —— 从个股详情页进入价格页时取不到数据。
- 修 ST 涨停价 —— 主板 ST 涨跌幅按 10% 计算（原按 5%），涨跌停价改取行情接口返回值。
- 修 最新价 −P% —— 少一分钱的进位错误。

**界面**

- 功能名统一：染色设置 → 高亮颜色设置、板块只留三项 → 板块显示单行、市场概览压矮 → 市场概览高度优化、隐藏理财项 → 底栏隐藏理财入口、隐藏新股申购提醒 → 隐藏 新股申购 弹窗。
- 全 App 箭头重画为同一套，跟随深浅色。
- 修 切换深浅色后界面残留一层灰膜。
- 修 使用前须知点「免责声明」打不开全文。

**设置页**

- 新增 日志导出 —— 设置 → 日志；导出模块与金太阳两个进程的日志。
- 新增 日志等级 —— 关闭 / 错误 / 信息 / 调试。
