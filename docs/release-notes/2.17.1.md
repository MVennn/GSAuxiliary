## 本版内容

- 概览页：顶部状态卡能分清三种情况了 —— 没连上 LSPosed 是灰的、连上但没勾作用域是红的、正常工作是绿的。
- 概览页：状态卡右下角的装饰图标放大，占满卡片右边的整条边缘。
- 概览页：「已激活」的绿色加深，版本号和 API 号统一成同一个灰度，不再一深一浅。
- 策略页：点股票直接跳个股详情页，不用再点一次标准行情。
- 策略页：筛选的三个条件改叫「涨家股票 / 跌家股票 / 自选股票」，不用猜「涨幅」筛的是什么。
- 策略页：左上角「策略个股」跟着筛选走，显示成「策略个股 3/15」，不再是一个永远不动的总数。
- 策略页：筛到一只不剩时显示国信自己的「未选出符合条件的股票」，不再是空白一片。
- 策略页：多选栏「取消」按钮左边多了「全选」按钮。
- 策略页：右上角三点菜单里多了「筛选股票」菜单项。
- 功能菜单：说不清位置的功能都补了副标题，比如智能盯盘入口标了「详情页底栏『自选』与『更多』之间」。
- 安装包：下载页只剩一个 `GSAuxiliary_*.apk`，不再附带 `-debug` 版。

---

需要 root + LSPosed（支持 API 102），适配国信金太阳 8.6.0 / Android 8.1+。  
安装步骤见 [README](https://github.com/SansKritO4/GSAuxiliary#安装)。
