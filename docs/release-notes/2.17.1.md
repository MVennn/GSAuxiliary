**策略筛选页更好用了，功能列表里那些啰嗦的说明也清掉了。**

## 本版内容

- 筛选的三个条件改叫「涨家股票 / 跌家股票 / 自选股票」，不用猜「涨幅」筛的是什么。
- 左上角「策略个股」现在跟着筛选走，显示成「策略个股 3/15」，不再是一个永远不动的总数。
- 筛到一只不剩时，显示国信自己的「未选出符合条件的股票」，不再是空白一片。
- 功能列表里大部分卡片只剩标题一行。原来的说明要么是标题换个说法，要么讲的是宿主内部怎么腾地方。
