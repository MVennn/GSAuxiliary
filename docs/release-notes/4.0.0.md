**四个功能从单点开关重构成一族可配置项 —— 底栏六格逐格可藏、自选高亮涨跌平各自配色、详情页底栏入口自己挑、复制规则按分组生效；底层同时修掉一批并发与泄漏问题。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/GSAuxiliary/issues/new/choose) 反馈 —— 崩溃、开关失灵请附上模块版本号与日志（设置页 → 日志 → 导出日志）。

## 本版内容

**底栏**

- 调整 自定义 底栏 入口 —— 功能页 → 底栏；原来只能藏「理财」，现在六格逐格挑（首页 / 行情 / 自选 / 交易 / 理财 / 账户），至少留一格；二级页「底栏入口设置」六个开关，即改即生效。

**股票详情页**

- 调整 自定义 详情页底栏 入口 —— 功能页 → 股票详情页；个股页「更多」面板七项里最多外提两项到底栏，图标与点击一并搬；满额时其余行置灰并说明仍在「更多」里。

**显示**

- 调整 自选股高亮 —— 功能页 → 显示 → 高亮颜色设置；涨 / 跌 / 平三档各自配色，原来三档共用一个颜色。

**自选**

- 调整 自选分组复制 —— 功能页 → 自选 → 复制设置；每条规则可选只对某个分组生效（任何分组 / 全部 / 自选 / 持仓股），同分组命中的规则优先，没有就回落默认规则。

**优化**

- 优化 配置变更 —— 恢复备份、重置这类连写多个键的操作不再逐个整份读盘，一次合流；单键改动到生效约 40ms。
- 优化 自选高亮 —— 每行少两次加锁与两次反射，长列表滚动更顺。
- 优化 日 K 缓存 —— 满了不再整张清空，按访问顺序淘汰，内存上限约 2 MB（原来每通道约 8.3 MB）。

**修复**

- 修复 日志队列没有上限 —— 某个钩子被高频触发时日志全堆在内存里；现在队列有界，满了就地写，不丢行。
- 修复 网络探针把凭据写进日志 —— 以前 Cookie、Authorization、openapi_sign 会进滚动日志、还能被「导出日志」带走；现在只在字节层命中签名参数时才解码，INFO 只留脱敏后的方法与地址。
- 修复 策略清单广播与调试通道没有输入上限 —— 任意 App 发一份大包就能拖住主线程；现在校验发送方，条目数与各字段长度全部封顶。
- 修复 H5 页面能调模块的 JS 桥 —— 以前桥挂在所有 WebView 上，任意页面都能触发「关页面 / 拉设置页 / 拉起个股详情」；现在只认自己挂的那个。
- 修复 一份脏备份让整片功能失效 —— 备份里一个字段类型写错（例如把布尔写成字符串），宿主侧读快照会整份回落默认、所有功能一起静默失效；现在逐字段归一，归不了的跳过并记日志。
- 修复 会话快照可能读到「新 session + 旧 sign」 —— 六个字段改成一次性发布的不可变快照。
- 修复 导出日志可能越界 —— 读线程写、主线程超时后取值会撞上 `StringBuilder`；换 `StringBuffer` 并封顶 4 MB。
- 修复 策略组合取数没有响应体上限 —— 封顶 4 MB，与其它通道同口径。
- 修复 截图文件名可能跳出目录 —— 文件名自净，去掉 `/`、`..` 与控制字符。
- 修复 方案名带换行时页面按钮消失 —— init 脚本转义补齐换行与 U+2028/U+2029。
- 修复 代码串解析四套各自一份 —— 收成一个入口（宽松 / 推导 / 严格三种口径显式命名），筛选、全选、聚合、截图四处改调它。
- 修复 计数文案两侧靠注释维持一致 —— 左上角「已选 N 只」的格式串与正则收成唯一口径，筛选与聚合都调它。
- 修复 全选偶尔拿上一轮的行下标点行 —— 发布顺序前移到「装完代理」之后、「搬勾选」之前。

> **注意**：功能页里四个开关换了名字与形态 —— 「隐藏 理财 入口」→「自定义 底栏 入口」、「自选股高亮」多了三档配色、「增加 智能盯盘 入口」→「自定义 详情页底栏 入口」、「自选分组复制」多了「适用分组」。
> 老配置不用迁移，升级后行为与原来一致。
