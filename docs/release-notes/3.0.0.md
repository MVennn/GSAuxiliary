## 迁移指引（装过旧版必读）

包名从 `io.github.SansKritO4.GSAuxiliary` 迁移为 `io.github.MVennn.GSAuxiliary`
（作者 GitHub 用户名改名，一并更新了模块收录）。对系统来说这是一个**全新应用**：
不能覆盖安装，旧版从此不再更新。迁移只要一分钟：

1. 打开**旧版** GSAuxiliary → 设置 → 「备份模块配置」，导出一份备份文件
   （`gsauxiliary-backup-*.json`）
2. 卸载旧版，LSPosed 管理器里旧模块一并移除
3. 安装本版 APK，LSPosed → 模块里勾选 GSAuxiliary，作用域勾「国信金太阳」
4. 强制停止国信金太阳，再打开一次
5. 打开新版 GSAuxiliary → 设置 → 「恢复模块」，导入第 1 步的备份，设置原样回来

没装过旧版的新用户不用管上面这些，按 [README](https://gitlab.com/M.Venn/gsauxiliary#安装) 装就行。

## 本版内容（含 2.17.2 / 2.17.3 / 2.18.0 的未发版改动）

### 迁移

- 包名与模块唯一 ID 迁移至 `io.github.MVennn.GSAuxiliary`，模块收录同步切换到新仓库；
  旧包（≤ 2.17.1）永久停更

### 设置页

- 「热重载目标进程」入口移除，「框架操作」分组随之消失——它只是个手动触发开关，
  日常用不上；APK 升级时框架本来就会自动热重载，这条能力原样保留
- 备份与日志导出的文件名前缀由 `gszx-` 更名为 `gsauxiliary-`，一眼能认出文件是谁家的

### 修复

- 「日志输出等级」开关此前不生效：切到「关闭」日志照记不误——现在真的关得住，
  选「关闭」还会顺带清空已有日志

### 界面

- 二级菜单漏网的副标题清干净：滑动设置、染色设置页一行是一行
- 关于页请出开发者向字段（技术细节组、作用范围、目标框架等），用户看不懂的不上界面
- 概览页状态卡的装饰图标收敛为完整显示，不再像一条乱入的曲线

需要 root + LSPosed（支持 API 102），适配国信金太阳 8.6.0 / Android 8.1+。  
安装步骤见 [README](https://gitlab.com/M.Venn/gsauxiliary#安装)。
