## 本版内容

**策略页**

- 优化 截图并添加 —— 截完一张不再等相册写完就翻下一页；99 只实测从约 91~93 秒降到 54.9 秒（约 0.93 → 0.55 秒/只）。
- 优化 截图并添加 —— 复用截图缓冲区，长批次的内存抖动与卡顿减少。
- 优化 截图并添加 —— 数据就绪检查更勤，单页平均少等 30~60 毫秒。
- 修复 排障日志 —— 截图批次收尾记录切页 / 就绪 / 拷贝 / 存盘耗时，变慢时能定位在哪一段。
