## 本版内容

**策略页**

- 加固 全选确认添加 —— 极端情况下，「全选」首轮逐行点击如果抛出异常，「确认添加」按钮会从此置灰（要换页或重开开关才能恢复）。现在出错就地收尾解锁，再按一次即可重来；正常使用的行为与上一版完全一致。
- 维护 —— 模块内部的宿主字段登记表补齐 5 个候选字段（供宿主改版后对账，用户不可感知）。
