**智能盯盘新增价格页一键配置、卡片跳转详情与保存免确认，修掉取数失败；设置页可一键导出日志。**

## 本版内容

**智能盯盘**

- 新增 价格页一键配置 —— 功能页 → 智能盯盘；价格页保存按钮右侧，按方案自动填入涨到、跌到。
- 新增 方案设置 —— 功能页 → 智能盯盘 → 价格页一键配置；涨到、跌到各是一串取值项，多套方案可设默认、排序，出厂自带一套「默认方案」。
- 新增 盯盘数据卡片拓展 —— 我的盯盘列表，点击数据卡片进入个股详情页。
- 新增 无需确定保存盯盘 —— 保存成功不弹确认，轻提示后自动返回。
- 新增 保存后返回位置设置 —— 保存后回个股详情页，或只回上一页。
- 新增 优化确定逻辑 —— 涨到、跌到都空着也能保存，即把该股移出我的盯盘。
- 新增 最近前高、最近前低 —— 取值项取现价上方、下方最近的局部顶 / 底。
- 新增 配置按钮设置 —— 多套方案时弹出选择方案弹窗。
- 调整 配置并保存只在价格页出现 —— 涨跌幅、换手率等页签不再显示这颗按钮。

**修复**

- 修复 取数失败 —— 从个股详情页进入价格页时取不到数据。
- 修复 保存后返回 —— 从个股详情页进入保存后返回会掉回首页，退回盯盘列表时数量不刷新。
- 修复 保存免确认 —— 空数据保存时确认弹窗不消失。
- 修复 ST 涨停价 —— 主板 ST 涨跌幅按 10% 计算（原按 5%），涨跌停价改取行情接口返回值。
- 修复 最新价 −P% —— 少一分钱的进位错误。
- 修复 删除方案或取值项 —— 下面那行会跟着跳一下。

**界面**

- 功能名统一：染色设置 → 高亮颜色设置、板块只留三项 → 板块显示单行、市场概览压矮 → 市场概览高度优化、隐藏理财项 → 隐藏 理财 入口、隐藏新股申购提醒 → 隐藏 新股申购 弹窗、备份模块配置 → 备份配置、恢复模块 → 恢复配置。
- 全 App 箭头重画为同一套，跟随深浅色。
- 修复 切换深浅色后界面残留一层灰膜。
- 修复 使用前须知点「免责声明」打不开全文。

**设置页**

- 新增 日志导出 —— 设置 → 日志；导出模块与金太阳两个进程的日志。
- 新增 日志等级 —— 关闭 / 错误 / 信息 / 调试。

## 注意

- 持仓成本价暂取不到数据 —— 方案里选了这一项，点配置会整体不填并提示取数失败。
