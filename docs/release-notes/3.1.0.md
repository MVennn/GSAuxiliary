## 新功能：智能盯盘价格页一键配置

盯盘的价格页，底部「保存」右边多一个**配置**按钮（底色取个股详情页「买」的红），
点一下就按你自己搭的方案把「最新涨到 / 最新跌到」填好，保存键自动变可点。

- 功能页新增分区「智能盯盘」→ 增加 配置 按钮 → 方案设置
- 方案自由搭：涨到 / 跌到各是取值项列表（最新价、涨停价、N 日最高价、
  最新价 ±p% 等 18 种），多值时取最大 / 最小 / 平均；可多套方案、设默认、排序
- 默认方案「30 日高低」出厂即用：涨到 30 日最高价、跌到 30 日最低价
- 取不到数据的项（断网、停牌）整体放弃并轻提示，绝不写半截值；
  涨到 / 跌到填反了输入框描边变红提示
- 套用后不自动保存——价格你还可以改，落库由你自己点「保存」

## 设置页

- 二级页支持弹层了（方案菜单、删除确认），外观与一级页一致

## 说明

- 方案数据跟随「备份 / 恢复 / 重置」：重置 = 恢复出厂方案，不会清掉你搭的方案
- 持仓成本价取值项本版暂以「无持仓数据」处理，后续版本接入宿主持仓后可用
