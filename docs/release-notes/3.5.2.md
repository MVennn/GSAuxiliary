## 本版内容

**策略页**

- 修复 筛选下确认添加 —— 策略详情 → 筛选 → 全选 / 手动勾选 → 确认添加；以前有筛选时，加进分组的是**另一批股票**（宿主按列表位置取票），屏幕上勾着的一只都没进去，再确认又只提示「已在该组合」。现在提交的就是你勾选的那些。
- 修复 全选失灵 —— 「确认添加」返回后「全选」点了没反应；宿主残留的上一批选中记录被当成数据不一致，整轮放弃。
- 修复 勾选显示 —— 筛选下全选后屏上只画出一部分对钩、底部却已显示全选。
- 修复 重复补点 —— 个别情况下列表会被反反复复点满四轮才停。
