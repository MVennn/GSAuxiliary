**自选页复制按钮支持规则化复制与图片 / PDF 导出；修掉策略全选对钩与一批底层问题。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/GSAuxiliary/issues/new/choose) 反馈 —— 崩溃、开关失灵请附上模块版本号与日志（设置页 → 日志 → 导出日志）。

## 本版内容

**自选**

- 新增 自选分组复制 —— 功能页 → 自选；自选页右上角的「编辑」按钮换成复制按钮，短按按当前规则复制当前分组的股票。
- 新增 复制设置 —— 功能页 → 自选 → 复制设置；可自选字段与顺序（名称、代码、涨跌、涨幅、涨速、流通市值、换手率、市盈率等 35 项），支持纯文本 / Markdown / CSV / JSON / 自定义模板，以及排序与空值处理。
- 新增 复制按钮设置 —— 功能页 → 自选 → 复制按钮设置；控制长按复制按钮是否弹出动作菜单。
- 新增 导出图片 / PDF —— 长按复制按钮；图片支持简洁列表 / 表格 / 卡片三套样式、深色、每 30 行分页，PDF 支持 A4 竖版 / 横版 / 单页长图；导出后可走系统分享。

**策略页**

- 修复 全选对钩 —— 策略详情多选全选后个别行的对钩不显示，再点一下计数反而 +1。
- 调整 截图并添加 按钮宽度 —— 底栏不再把「已选 N 只股票」挤成两行。
- 修复 截图并添加 —— 策略页销毁时释放等待详情页的股票列表，避免页面残留引用。

**修复**

- 修复 策略直达行情 —— 筛选生效且有条目转换失败时，兜底路径可能打开另一只股票。
- 修复 截图就绪门禁 —— 首次进入详情页太早时，不再让整个进程退化成「不检查 K 线数据」。
- 修复 配置备份 —— 小数形式的颜色值不再被静默截断，截断时会记日志。
- 修复 代码检查 —— 补全宿主字段契约提取，静态不变量不再误报（行为零变更）。
